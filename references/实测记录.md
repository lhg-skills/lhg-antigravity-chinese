# 实测记录

## 2026-10-13 macOS Apple Silicon

- 机器：macOS 15.3.1，Apple Silicon，Node v22.22.2
- 客户端：Antigravity 2.23.0（/Applications/Antigravity.app）
- 引擎：qqxpee/antigravity2-cn（localization_engine.js + dicts/）
- 过程要点：
  1. 首次运行安装脚本，sudo 提权成功，但备份阶段报 `EPERM: operation not permitted, copyfile ... app.asar.bak`。
  2. 定性：macOS 13+「App 管理」TCC 权限限制，root 也无法修改 /Applications 内 App 包内容；与密码无关。
  3. 修复：系统设置 → 隐私与安全性 → App 管理 → 打开所用终端开关，重跑一次通过。
  4. 引擎自动：备份 app.asar.bak → 注入 preload 翻译层 → 重打包 → 清除隔离属性 → 应用自签名。
  5. 重启 Antigravity，界面（菜单/设置/登录页）变简体中文；编辑器与 AI 对话不翻译，符合设计。
- 该踩坑沉淀为入口脚本的 EPERM 自动诊断输出。

## 2026-10-13 Windows

- 机器：Windows 11，Node.js 22.22.2
- 客户端：Antigravity 2.23.0
- 引擎：huashuimoyv/antigravity-chinese（MIT）
- 过程要点：
  1. `node cli.js check` → `{"supported": true, "state": "未汉化，可安装"}`
  2. `node cli.js install` → `"已安装本地汉化补丁"`，原版自动备份至 `resources\.antigravity-local-zh\`
  3. 启动验证界面中文化成功；`node cli.js restore` 可逐字节还原（SHA-256 与官方原包一致）。
